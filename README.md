# Biomedical Internship Tracker

US STEM summer internships at biomedical and medical-device companies, read
straight from each company's job board and refreshed every day.

Each listing links to the employer's own posting. Apply there; this repository
only collects links.

- **Who it's for:** students looking for engineering, software, data, science,
  quality and regulatory internships in medtech.
- **What's included:** internships and summer co-ops in the US for the season
  below. Full-time, non-STEM, off-season and PhD-only roles are filtered out.
- **What's not:** this list is only as complete as each company's public job
  board. A missing company or role doesn't mean nothing is open. Check the
  company's careers page too.

Listings that close move to [CLOSED.md](CLOSED.md). The raw data is in
[`data/listings.json`](data/listings.json).

## How it works

A scheduled GitHub Action runs `python -m tracker refresh` once a day. For each
company in [`companies.toml`](companies.toml) it:

1. Reads the job board's public JSON API (Greenhouse, Lever, SmartRecruiters,
   Eightfold or Phenom).
2. Screens every posting: it must be an internship or summer co-op, in the US,
   STEM, for the target summer, and not PhD-only.
3. Updates the catalog. A posting missing from a successful read on two
   different days is closed. A company whose read fails is left untouched.
4. Validates the catalog against
   [`tracker/listing.schema.json`](tracker/listing.schema.json) and regenerates
   this README and `CLOSED.md`.

The run commits to a branch, opens a pull request and merges it once its checks
pass.

## Development

Requires Python 3.11 or newer.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

ruff check . && ruff format --check .
pytest
python -m tracker validate
python -m tracker refresh --dry-run   # live read, writes nothing
python -m tracker render              # rebuild README.md and CLOSED.md
python -m tracker close <listing-id>  # close a listing by hand
```

Tests mock all HTTP and never touch the network. To add a company on a supported
platform, add an entry to `companies.toml`. To add a platform, see
`tracker/sources/__init__.py`.
